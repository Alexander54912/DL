    1. Свой Dataset и ImageFolder

    из семинара

    1 Зачем

    CIFAR лежит в torchvision «из коробки». Реальные картинки — папки на диске: нужен Dataset с __len__ / __getitem__, либо готовый ImageFolder.

    2 Интуиция

    ≈ 7 тыс. jpg, 150 классов; svg пропускаем. Делим внутри каждого класса 75/25, чтобы в тесте были все покемоны.

    3 Определение

    Dataset: контейнер пар (вход, метка). DataLoader батчит и перемешивает. ImageFolder(root) сам берёт имена классов из подпапок.

    path → PIL RGB label: int ∈ {0..C−1} после transform: (C,H,W)

    4 По шагам

    1. classes = sorted(подпапки) — порядок задаёт номер класса.
    Иначе метки «прыгают» между запусками.
    2. Для каждого класса: список jpg → train_test_split(..., random_state=42).
    Stratify по классам «вручную».
    3. __getitem__: открыть / взять из RAM → transform → (tensor, label).
    load_to_ram=True ускоряет эпохи на маленьком датасете.

    5 Числовой пример

    150 классов × ≈45 картинок ≈ 6750 файлов. Train 75% ≈ 5062, test ≈ 1688.

    классов: 150 | train≈5062 | test≈1688 | ImageFolder на MRI Training/ тоже работает

    6 Интерактив

    Сколько файлов попадёт в train?

    Попробуйте: n_per_class=40, test_size=0.25 → train 30 на класс; смените test_size.

    7 Код

    class PokemonDataset(Dataset):
    def __init__(self, root, train=True, transform=None, test_size=0.25):
        self.classes = sorted(d for d in os.listdir(root)
                              if os.path.isdir(os.path.join(root, d)))
        self.files, self.labels = [], []
        for y, name in enumerate(self.classes):
            names = sorted(f for f in os.listdir(os.path.join(root, name))
                           if f.endswith('jpg'))
            tr, te = train_test_split(names, test_size=test_size, random_state=42)
            pick = tr if train else te
            self.files += [os.path.join(root, name, f) for f in pick]
            self.labels += [y] * len(pick)
        self.transform = transform
    def __len__(self): return len(self.files)
    def __getitem__(self, i):
        img = Image.open(self.files[i]).convert('RGB')
        if self.transform: img = self.transform(img)
        return img, self.labels[i]

    2. Трансформы под ImageNet

    из семинара

    1 Зачем

    Предобученный ResNet ждёт те же препроцессинг, что на ImageNet: 224×224 и нормализацию mean/std. Иначе fine-tuning «бьётся» с чужим распределением входов.

    2 Интуиция

    3 Определение

    $\tilde x_c = (x_c - \mu_c)/\sigma_c$, где $\mu=[0.485,0.456,0.406]$, $\sigma=[0.229,0.224,0.225]$ (каналы RGB, значения после ToTensor в $[0,1]$).

    PIL → Resize/Crop ToTensor: (3,224,224) ∈ [0,1] Normalize → ~N(0,1)-ish

    4 По шагам

    1. Resize(256) — меньшая сторона = 256, пропорции сохранены.
    Единый масштаб до кропа.
    2. Test: CenterCrop(224). Train (с аугментациями): часто RandomResizedCrop(224) + Flip.
    Детерминизм на тесте.
    3. ToTensor + Normalize(mean, std) ImageNet.
    Совместимость с pretrained weights.

    5 Числовой пример

    Пиксель R=0.485 после ToTensor: $z=(0.485-0.485)/0.229=0$. Пиксель R=1: $z\approx 2.25$.

    6 Интерактив

    Train vs test пайплайн

    Включите аугментации — на test они должны исчезнуть.

    7 Код

    normalize = T.Normalize(mean=[0.485, 0.456, 0.406],

test_tf = T.Compose([

    T.ToTensor(), normalize])

    8 Грабли

    • Normalize до ToTensor (PIL 0..255) — неверные μ/σ.
    • Аугментации на val/test → метрики шумят и завышены.
    • Два ImageFolder на одни файлы: для train/val нужны разные transform + непересекающиеся Subset.

    9 Где в жизни

    • Единый preprocess в inference-сервисе = тот же, что при обучении pretrained.

    Какой размер ждёт ResNet18 ImageNet?

    11 Шпаргалка

    Resize(256) → CenterCrop(224) → ToTensor → Normalize(ImageNet). Аугментации только на train.

    4. Fine-tuning: fc, группы параметров, dual lr

    из семинара сверх курса

    1 Зачем

    Голова ImageNet на 1000 классов нам не нужна. Меняем model.fc, решаем что разморозить и с каким lr: тело уже «умеет видеть», голова учится с нуля.

    2 Интуиция

    3 Определение

    ResNet18: fc был Linear(512, 1000) → Linear(512, C). Trainable params = сумма p.numel() с requires_grad=True.

    features: (N,512) fc.weight: (C,512) logits: (N,C)

    4 По шагам

    1. Загрузить weights ImageNet, заменить fc.
    Новая голова — случайная инициализация.
    2. Либо учить всё одним lr, либо param_groups: body / head с разными lr.
    Не сбить низкоуровневые фильтры большим шагом.
    3. Head-only: freeze all → unfreeze fc; в optimizer только model.fc.parameters().
    Меньше памяти и графа.
    4. Тонкость BN: при model.train() замороженный BatchNorm всё ещё обновляет running mean/var. Для «камня» — eval() на замороженных модулях.
    Иначе статистика BN уезжает на маленький домен.

    5 Числовой пример

    C=150: голова $512\cdot150+150=76950$ параметров. На МРТ: часто размораживают layer4+fc.

    6 Интерактив

    Режим дообучения

    Переключите full / head / layer4+fc — смотрите, что попадает в optimizer.

    • Считать, что requires_grad=False останавливает BN running stats — нет.

    5. Learning rate schedulers

    из семинара сверх курса

    1 Зачем

    В начале полезен большой шаг, ближе к концу — маленький. Scheduler меняет lr по правилу; optimizer решает куда, scheduler — насколько.

    2 Интуиция

    Step — ступеньки вниз; Cosine — плавная дуга до ~0; warmup — разгон с малого lr (стабильность больших батчей / трансформеров); OneCycle — вверх и вниз за один цикл эпох.

    3 Определение

    StepLR: $\eta_{t}=\eta_0\cdot\gamma^{\lfloor t/\text{step}\rfloor}$

    CosineAnnealing: $\eta_t=\eta_{\min}+\frac12(\eta_0-\eta_{\min})\big(1+\cos(\pi t/T_{\max})\big)$

    Warmup (линейный): $\eta_t=\eta_{\text{peak}}\cdot t/W$ при $t<W$, далее cosine/const.

    4 По шагам

    1. Создать optimizer с начальным lr.
    Scheduler читает param_groups.
    2. После optimizer.step() (обычно раз в эпоху) вызвать scheduler.step().
    Порядок важен; у OneCycle — часто раз в batch.
    3. Логировать opt.param_groups[0]['lr'].
    Иначе «lr не падает» незаметно.

    5 Числовой пример

    StepLR($\eta=0.01$, step=5, $\gamma=0.3$), эпохи 0..14: lr = 0.01 до эпохи 4, затем 0.003, затем 0.0009.

    После 2 ступенек: 0.01 × 0.3² = ?

    6 Интерактив

    Кривые расписаний

    Сравните Step, Cosine, Warmup+Cosine, OneCycle. Поменяйте T_max / warmup.

    Cosine StepLR Warmup+Cosine OneCycle

    6. Другой домен: МРТ

    из семинара

    1 Зачем

    Покемоны ≈ фото ImageNet. МРТ — серые срезы, 4 класса опухолей. Проверяем: помогут ли pretrained-края/текстуры, и чему верить кроме accuracy.

    2 Интуиция

    Высокая accuracy может означать «читерство»: сеть смотрит на рамку сканера, больничный watermark, разный контраст аппарата — а не на опухоль. XAI и правильный split ловят это.

    3 Определение

    4 класса: glioma / meningioma / pituitary / no tumor. Данные через ImageFolder; серый снимок → 3 одинаковых канала (ResNet ждёт RGB).

    ImageFolder → RGB logits (N,4) CE + accuracy ≠ доверие

    4 По шагам

    1. Два ImageFolder на Training: с aug и без; Subset с непересекающимися индексами для train/val.
    Иначе aug попадёт на val.
    2. Testing не трогать до финала.
    Нет утечки выбора гиперпараметров.
    3. FT: часто unfreeze layer4+fc (домен далёкий).
    Низкие слои универсальны, верхние — под задачу.
    4. Смотреть confusion / XAI: область опухоли или край кадра?
    Accuracy без локализации — ложное спокойствие.

    5 Утечки и смещения

    • Patient leakage: срезы одного пациента в train и test → завышенная метрика.
    • Scanner bias: класс коррелирует с аппаратом/больницей.
    • Preprocess leakage: нормализация статистики по всему датасету включая test.
    • Label leakage: в кадре видны аннотации/стрелки врача.

    7. Объяснимость (XAI): методы

    из семинара из лекции

    1 Зачем

    Модель выдаёт класс, но не «почему». Attribution присваивает каждому пикселю вклад в логит выбранного класса — так ловят читерство (подпись, фон, край кадра).

    2 Интуиция

    Градиентные методы — быстрый обратный проход. Возмущения (occlusion) — медленнее, но интуитивны. Ни один метод не «истина»: смотрите несколько и sanity-check на известных объектах (котёнок слева / щенок справа).

    3 Определение

    Saliency: $\displaystyle\left|\frac{\partial f_c(x)}{\partial x}\right|$ — шумная «крапинка», страдает от насыщения.

    Deconv: через ReLU пропускает только положительный входящий градиент (игнор знака активации).

    Guided Backprop: нужно и $z>0$, и входящий grad $>0$ — чистые контуры, но слабо зависят от весов.

    CAM / Grad-CAM: $$L^c=\mathrm{ReLU}\Big(\sum_k \alpha_k^c A^k\Big),\quad \alpha_k^c=\frac1Z\sum_{i,j}\frac{\partial y^c}{\partial A^k_{ij}}$$ карта «пятнами» (у ResNet18 layer4: 7×7 → upsample).

    Guided Grad-CAM: поэлементное произведение Guided BP × Grad-CAM.

    Integrated Gradients: $$\mathrm{IG}_i(x)=(x_i-x_i^0)\int_0^1 \frac{\partial f(x^0+\alpha(x-x^0))}{\partial x_i}\,d\alpha$$ baseline $x^0$ (чёрный); лечит насыщение; ~$n$ обратных проходов.

    4 По шагам Grad-CAM

    1. Forward до выбранного слоя → карты $A^k$.
    Семантика «где» живёт в глубоких feature maps.
    2. Backward логита класса → усреднить градиент по H×W → веса $\alpha_k$.
    Важность канала для класса $c$.
    3. $\mathrm{ReLU}(\sum_k \alpha_k A^k)$, интерполировать до размера входа.
    Только положительный вклад в класс.

    5 Сравнение

    МетодЧто видноШум / риск
    Saliencyчувствительные пикселикрапинка, насыщение
    Guided BPконтурымало зависит от класса/весов
    Grad-CAMобласть объектагрубое пятно 7×7
    Guided Grad-CAMдетали в областинаследует минусы обоих
    IGпиксели вдоль путимедленнее; выбор baseline

    6 Числовой мини-пример IG

    1D: $f(x)=x^2$, $x=2$, baseline $x^0=0$. $\mathrm{IG}=(2-0)\int_0^1 2(\alpha\cdot2)\,d\alpha=2\cdot[2\alpha^2]_0^1=4$, и $f(2)-f(0)=4$.

    7 Код (Captum)

    from captum.attr import Saliency, LayerGradCam, IntegratedGradients, LayerAttribution

    8 Грабли

    • Красивая карта Guided BP ≠ верное объяснение класса.
    • ReLU(inplace=True) ломает Captum — выключить inplace.
    • Большой convergence delta у IG → увеличить n_steps.

    8. Виджет: карта важности на tiny CNN

    сверх курса идея семинара

    1 Зачем

    Почувствовать attribution без Captum: маленькая CNN в JS, считаем saliency и упрощённый Grad-CAM по единственной карте признаков.

    1 Зачем

    Классификация отвечает «что на картинке». Детекция — «где объекты (box)». Сегментация — «какие пиксели принадлежат объекту/классу».

    2 Интуиция

    3 Определение

    IoU (Intersection over Union): $\mathrm{IoU}=|A\cap B|/|A\cup B|$ для предсказанного и истинного box/маски.

    Семантическая сегментация — класс на пиксель (все машины = один класс). Instance — отдельные объекты.

    U-Net: encoder ↓ сжимает, decoder ↑ восстанавливает; skip-связи копируют детали с того же масштаба (важно для мед. масок).

    4 По шагам IoU

    1. Пересечение: max(0, x2−x1)·max(0,y2−y1).
    Площадь overlap.
    2. Объединение = area_a + area_b − intersection.
    Без двойного счёта overlap.
    3. IoU = inter / union ∈ [0,1]; порог 0.5 — классика детекции.
    mAP строится по IoU.

    7 Код

    def iou_box(a, b):  # a,b = (x1,y1,x2,y2)
    ix1, iy1 = max(a[0],b[0]), max(a[1],b[1])
    ix2, iy2 = min(a[2],b[2]), min(a[3],b[3])
    inter = max(0, ix2-ix1) * max(0, iy2-iy1)
    uni = (a[2]-a[0])*(a[3]-a[1]) + (b[2]-b[0])*(b[3]-b[1]) - inter
    return inter / (uni + 1e-8)
# U-Net idea: out = decode(encode(x), skips=encode_features)
